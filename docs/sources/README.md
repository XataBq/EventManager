Причина: Figma MCP вернул лимит вызовов Starter; `whoami` подтвердил тариф Starter. Содержимое и структура этих объектов прочитаны до лимита. При реализации проверить их визуально через доступный Figma-клиент или человеком; не считать их отсутствие отсутствием дизайна.

Внутри проверенного дерева UI-кита не найдено узлов COMPONENT, COMPONENT_SET или INSTANCE. Это набор фреймов-примеров; переиспользуемые Compose-компоненты предстоит создать. Публикуемые библиотеки и переменные всего файла отдельно не исследовались.

Приложенный пользователем PNG показывает заголовок блока 00 и служил указателем на раздел. Источник правил — тексты из Figma и запрос пользователя.

## Приоритет информации

1. Текущий запрос пользователя и последующие подтверждённые решения.
2. Актуальные подтверждённые ответы пользователя из `12-backend-answers-2026-10-27.md` и реестр `08-decisions.md`; при расхождении учитывать более поздний прямой ответ и исправлять основной документ.
3. Пояснения блока 00 и сценариев 01–04.
4. Mobile-макеты: композиция экрана.
5. Блок 06: визуальные токены и компоненты.

Разногласия регистрировать как Q-вопрос, не исправлять незаметно. Figma в ходе исследования не изменялась.
