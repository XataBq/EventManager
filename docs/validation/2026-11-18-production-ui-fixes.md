## Изменения

- Общий FormField использует Material3 OutlinedTextField, isError и supportingText: красные граница/label, одно сообщение под полем. Ошибка заменяет обычную подсказку. Имеющиеся callbacks, input transformations, пароль и keyboard actions сохранены.
- Ошибки входа/регистрации аккаунта, профиля, анкеты, приглашения волонтёра, ручного кода сканера и поискового поля аналитики привязаны к соответствующим полям. Общие transport errors остаются ошибками операции. Вопросы анкеты сгруппированы: нет разнесённых по внешним отступам help и error; подпись help в редакторе объясняет поведение.
- Публикация заранее применяет общую EventEditingPolicy.publicationErrors; обязательные поля помечены звёздочкой, неполный черновик по-прежнему можно сохранить. Название вопроса/пустые варианты и название блока программы подсвечиваются по ошибке валидации. Логика обязательности чекбоксов по уточнению пользователя не менялась.
- LazyColumn аналитики объединяет header/search/footer в отдельные Column; карточки билетов занимают полную ширину.
- TextAction и вторичные/опасные действия имеют видимую рамку; primary остаётся с акцентной заливкой.
- Общий фиксированный плюс на корнях «Мои билеты» и «Мероприятия» раскрывает создание или открытие мероприятия по ссылке/коду. Команды направляются в текущий стек. Старые дублирующие root-кнопки удалены из remote.
- EventPassRefresh отделяет read busy от пользовательского жеста. Автоматический refresh не запускает pull-индикатор; жест и accessibility refresh могут его показывать.
- TicketsViewModel опрашивает текущую видимую область каждые 5 секунд без команд/сканирования. Карточка обновляется отдельно от списков; stop отменяет polling и чтения, прежние owner guards сохранены.
- Receipt гостя опрашивается отдельно через TicketRepository.observeGuestTicket и capability только живого flow. Remote GET tickets/{id}?token=... не отправляет bearer, не сохраняет capability и не инвалидирует account session при отказе. При Used QR скрывается, показаны зелёная отметка и «Билет отсканирован. Проход разрешён»; fullscreen закрывается. Для своей карточки действует тот же Used результат. Статус receipt живёт в SavedStateHandle текущего flow.
- Превью remote-обложек — singleton DI provider с LRU памяти 12 MiB, ключ assetId, разграничение по session snapshot, mutex для совместного чтения/декодирования, очистка при смене actor перед обращением. Это память процесса, не постоянный disk cache; bounds/MIME/origin проверки transfer сохранены.
- В remote receipt убрана ошибочная подпись о demo-письме; гостевой текст описывает QR текущего экрана и последующий доступ по письму/кабинету.
