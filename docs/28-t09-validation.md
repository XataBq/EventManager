## Реализовано и demo defaults

- Профиль в прежней третьей вкладке: имя Unicode, optional российский телефон/организация, reminders preference, read-only email/ID, copy ID, явный save, dirty Back/tab/logout Save/Discard, ошибка внутри confirmation, существующий logout. Имя хранится только в AuthData.names; Account/Session не меняются. Новые формы получают name/phone, прежние билеты/регистрации/answers/check-ins не переписываются. Несохранённые поля только в памяти и очищаются при hidden/background; нового PII saved state нет.
- Schema **5** в прежнем AtomicFile. V1–v4 читаются без reset; defaults phone/organization=null, notifications=true, сохранённое signup-имя остаётся. Все writers сохраняют соседние данные. После первой записи v5 **downgrade на code 17 с тем же snapshot не поддерживается**. Архивные code 15/17 не менялись. Сессии, raw secrets, outbox, cooldown, guest UI payload не стали persistent. [Единый контракт хранения](05-data-contracts.md).
- Реальный PDF своего current ACTIVE билета: выданные metadata/name/displayNumber/QR/manualCode, Cyrillic/native PDF, переносы и A4 pagination. Guest download/history/чужой билет не добавлены. Реальный XLSX owner E: один полный snapshot всех регистраций/статусов/answers, независимо от query/page; стабильные questionId/title/optionId, boolean checkbox, legacy Used без выдуманного времени/checker, SnapshotAt. Пользовательские строки — text cells, формул нет, QR/manual в XLSX нет.
- SAF CreateDocument/content URI, правильные MIME/имена, отмена/ошибка/явный повтор. Снимок читается после picker; доступ/личность проверяются перед подготовкой/перед provider, после open и по chunks/после close. Успех только после завершения записи. Private temp очищается finally/startup, broad storage permissions/Share не добавлены. Уже переданные provider байты отозвать нельзя: при ошибке/утрате доступа может остаться неполный внешний файл; успеха нет. Отменённый старый picker/job не выдаёт файл новой личности.
- Resend собственного current ACTIVE ticket идёт в прежний fake outbox, без новой регистрации/QR/места. Recipient из Registration, cooldown одну минуту задаёт FakeDocumentsPolicy по auth Clock, retryAt возвращается в результат. Явное нажатие до срока получает Cooldown; автоматического retry/UI таймера нет. Preference не отключает confirm/reset/выдачу билета/запрошенный resend; автоматическая необязательная рассылка отсутствует. UI честно сообщает demo outbox, реальной отправки нет.

Порты/владельцы/lifecycle/commit и границы — [архитектура T09](architecture/t09-profile-files.md). Удаление явно недоступно; demo reset не выдаётся за удаление аккаунта. HTTP jobs/production cursor/новый manual credential из API-предложения не внедрены.
